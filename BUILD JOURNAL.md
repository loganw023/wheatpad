# Build Journal

This project is from highway. Last summer, I soldered all the components down onto the PCB, installed circuitpython and copied the firmware, but the macropad did not work, so I put the project on hold for a while. I only picked up the project and finished it during outpost, in which I started building 07/02/2026, and finished 07/03/2026. 

## 07/02/2026

The work outlined was not thoroughly documented, and I only took a few pictures of the end product. The work outlined took place from around 4 pm to 10 pm which entails the troubleshooting effort leading towards a working end item. 

Today, I started by plugging in the macropad, but noticed that the macropad did not work. I ended up fixing a bunch of soldering joints that were poorly done last summer, which I think are a lot cleaner now. When plugging in the macropad again, I noticed that nothing worked. I first thought that this was a firmware issue, so I went through many iterations of the code to attempt to fix the issue, but none of these coding changes caused the macropad to work. When soldering, I realized that I accidently connected two soldering joints on the rotary encoder, being GND and Pin A, which I thought was the issue. I then spent an hour attempting to separate the two joints from each other, which I managed to do, but I destroyed the rotary encoder pins. When going back, I again realized that NOTHING worked once again. From here, I decided to use a multimeter to check if electricity could flow throughout the PCB. I proceeded to perform continuity mode tests as well as accidental ground short tests. The PCB passed all these tests, which made me more confused. I then thought that the issue was the pin assignments, but that also wasn't the issue. I ended up using a paper clip to act as a bridge between the XIAO GND pin and certain GPIO pins mapped to the switches on the XIAO, which caused the letters to be printed, which helped me determine that the issue was most likely broken traces on the PCB, specifically the common GND trace that all my switches were connected to. From here, I used a wire I had from an introductory arduino kit and soldered it between one of the switch's GND pin and the XIAO GND pin. This caused the switches to work. 

## 07/03/2026

Today, I cleaned up the GND wire I added to be more discrete to allow the PCB to fit in the case, and put the PCB in the case and screwed the lid onto the bottom. I realized that I lost the OLED screen the kit came with, but ultimately the screen was not essential to the functionality of the product, so I think it's fine without the OLED. Additionally, the rotary encoder does not work still, which I think is not only because of the mishap with the soldering job, but also because of issues with the traces on the PCB. In the end, the switches still work, which is the main purpose of the macropad for me anyways, so I'm pretty happy with the product!
